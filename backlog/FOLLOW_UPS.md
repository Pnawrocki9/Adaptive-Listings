3. Keep un-promoted entries here as BACKLOG candidates.

the stub.

  `variant_index` through Decision API → SDK → `TextDirective` so the correct variant copy is
  rendered.
- **ac:**

  - [ ] SDK: `TextDirective` includes `variant_index`; `adapt.ts` selects
        `slot.variants.en[variant_index]` (falls back to `slot.en` if variants not present)
  - [ ] ClickHouse: `variant_index` logged alongside impression event for feedback loop
  - [ ] Tests: bandit unit test covers all 3 variant indices being selectable

## FOLLOW-002 — Build GET /api/adapt/description endpoint + Modal job (DESC-001)

- **source_retro:** RETRO-001
- **source_ticket:** TICKET-046
- **recommended_sprint:** 9
- **recommended_agent:** backend-engineer (endpoint + Redis) + ml-engineer (Modal job)
- **priority:** P1
- **estimated_hours:** 8
- **scope:** `PlaybookEntry.copy_template.en` now exists for all 17 non-neutral archetypes. This
  follow-up builds the full description pipeline described in Master Design E.7: (1)
  `GET /api/adapt/description` endpoint with tier-gating logic, (2) Redis cache with per-tier TTL
  (72h Tier 2 / 48h Tier 3), (3) Modal async job calling Sonnet 4.6 with `copy_template.en` as seed,
  (4) `listing.updated` Redpanda event → Redis cache invalidation. Tier 1 gets `copy_template.en`
  statically with no caching or Modal invocation.
- **ac:**
  - [ ] `GET /api/adapt/description?listing_id=&archetype=&tier=&locale=` returns
        `{ description, source: 'ai_cached'|'ai_generated'|'template_fallback', locale, generated_at }`
  - [ ] Tier 1: returns `template_fallback` immediately, no Redis, no Modal queue
  - [ ] Tier 2/3 cache hit: returns `ai_cached` from Redis within 10ms
  - [ ] Tier 2/3 cache miss: returns `template_fallback` immediately + enqueues Modal job async
  - [ ] Modal job: Sonnet 4.6 generates description, writes to Redis, subsequent request returns
        `ai_cached`
  - [ ] `listing.updated` event invalidates Redis key `desc:{tenant_id}:{listing_id}:*`
  - [ ] Integration test covers all 3 source values and cache invalidation
- **promoted_to_queue:** false
