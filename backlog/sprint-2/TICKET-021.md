# TICKET-021: tenants table schema + RLS policies + auto-onboarding fields (v1.1)

## Summary

The first real Postgres schema: `tenants` table per Master Design J.3. Includes ALL v1.1 auto-onboarding fields (`data_schema`, `onboarding_status`, `primary_url`, `detected_platform`, `schema_health_score`, `last_drift_detected`, `auto_recovery_enabled`). Plus RLS policies enforcing tenant isolation. Seed script for dev with 3 sample tenants (Marbella ES, Warsaw PL, London UK matching pilot plan).

## Context

The `tenants` table is foundational. Every other table will FK to it. Master Design J.3 (v1.1) lists the fields. Important: this is the moment we need to be careful — getting these fields right now saves a painful migration later.

RLS strategy: every authenticated query carries a JWT with `tenant_id` claim. RLS policy `tenant_isolation` allows access only when `tenant_id` matches JWT claim. Migrations and admin tasks bypass RLS via service role key.

## Implementation guidance

Drizzle schema:

```typescript
// packages/db/src/schema/tenants.ts
import { pgTable, uuid, text, jsonb, boolean, timestamp, integer, real, check } from 'drizzle-orm/pg-core';
import { sql } from 'drizzle-orm';

export const tenants = pgTable(
  'tenants',
  {
    tenantId: uuid('tenant_id').primaryKey().defaultRandom(),
    displayName: text('display_name').notNull(),
    region: text('region').notNull(),
    tier: text('tier').notNull().default('observer'),
    brandTokens: jsonb('brand_tokens').default({}),
    brandVoice: jsonb('brand_voice').default({}),
    signalsEnabled: jsonb('signals_enabled').default([]),
    adapters: jsonb('adapters').default({}),
    fairHousingRules: text('fair_housing_rules').notNull().default('eu_standard'),
    privacyMode: text('privacy_mode').notNull().default('session'),
    consentHelperEnabled: boolean('consent_helper_enabled').notNull().default(false),
    whiteLabel: jsonb('white_label').default({}),
    webhookUrl: text('webhook_url'),
    auditRetentionDays: integer('audit_retention_days').notNull().default(90),
    
    // v1.1 — Auto-onboarding
    dataSchema: jsonb('data_schema'),
    onboardingStatus: text('onboarding_status').notNull().default('pending'),
    primaryUrl: text('primary_url'),
    detectedPlatform: text('detected_platform'),
    schemaHealthScore: real('schema_health_score').default(1.0),
    lastDriftDetected: timestamp('last_drift_detected', { withTimezone: true }),
    autoRecoveryEnabled: boolean('auto_recovery_enabled').notNull().default(true),
    
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
    deletedAt: timestamp('deleted_at', { withTimezone: true }),
  },
  (table) => ({
    regionCheck: check('region_check', sql`${table.region} IN ('eu','us','uk','uae')`),
    tierCheck: check('tier_check', sql`${table.tier} IN ('observer','augment','native')`),
    onboardingStatusCheck: check('onboarding_status_check', sql`${table.onboardingStatus} IN ('pending','auto_detecting','ready','needs_review')`),
    healthScoreCheck: check('health_score_check', sql`${table.schemaHealthScore} BETWEEN 0 AND 1`),
  }),
);
```

After `pnpm db:generate`, the SQL will be in `migrations/0001_*.sql`. Manually append RLS:

```sql
-- migrations/0001_create_tenants.sql (after auto-generated DDL)

ALTER TABLE tenants ENABLE ROW LEVEL SECURITY;

CREATE POLICY tenant_isolation ON tenants
  FOR ALL
  TO authenticated
  USING (tenant_id = (current_setting('request.jwt.claims', true)::json ->> 'tenant_id')::uuid)
  WITH CHECK (tenant_id = (current_setting('request.jwt.claims', true)::json ->> 'tenant_id')::uuid);

CREATE INDEX tenants_region_active_idx ON tenants (region) WHERE deleted_at IS NULL;
```
