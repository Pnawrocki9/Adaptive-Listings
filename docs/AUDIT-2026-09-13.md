## 1. Verdict in one screen

1. **The production chain is real end-to-end on the POST path** (SDK → ingest → ClickHouse →
   `/api/adapt` with a grounded Anthropic call → DOM → feedback → rollup), and the FOLLOW-819
   harness is an honest instrument for that chain. Cold start, outage posture, the consent gate, the
   §H.9 opt-out, the §E.7.0 withhold and the fact-check judge are all built and tested. Archetype
   reachability is 18/18 (the "13/18" figure in session memory was stale).
2. **FOLLOW-820 condition 1 cannot be graded honestly at HEAD.** The one committed artefact predates
   27 commits and records AC(2) red; the harness's AC(1) passes on a refused batch that served a
   canned English CTA (FOLLOW-1186); the cosine ranking the differentiator exists to prove has
   **zero observations anywhere** because both embedding seeders are dead at HEAD (a `.mts`→`.ts`
   import failure since 2026-06-25, masked by `continue-on-error`) and the surviving seeder can only
   write to hosted Supabase, never to the local Postgres; the harness still defaults to a
   CORS-refused port and accepts the Turbo-stripped-env 500 as a healthy control plane; and the SoT
   plus FOLLOW-820's own stub still say the condition is an open gap / not gradeable.
3. **The measured pilot's numbers would not be evidence.** "Adapted" is a decision row, not an
   exposure; the conversion is any CTA click, forgeable by anyone holding the page-visible key; no
   demo, synthetic or ops traffic is excluded; there is no sample-ratio check; two readers render a
   dead arm as `0.00 %` / `-100 %`; and the holdout rate is a client body field. None of this blocks
   condition 1 as ESC-073 restated it. All of it blocks reading any post-GO number as proof.
4. **Security grades EXPOSED for the pilot, not for tenant isolation.** The application-layer tenant
   fence holds everywhere. The two backstops the design leans on — RLS and request signing — are
   both non-enforcing; bearer JWTs never expire; the consent-registration replay defence is dead
   code; no LLM path has a system prompt or data delimiters; FOLLOW-1169 is still live.
5. **Compliance is honest but thin at the record layer**, and one ruling has to be re-taken: both
   fair-housing tickets were cancelled on premises that `family_stage` inference and `reorder`
   directives have since falsified. k-anonymity ≥ 50 and ε ≤ 2 exist only in prose, once with a ✅.
6. **Documentation lags code in both directions.** Redpanda and LiteLLM survive in the two
   onboarding documents every session boots from; §Snapshot describes three deleted apps; the root
   README says a pilot is live on production, which ESC-020 measured at zero.
